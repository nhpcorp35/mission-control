# Contradiction Detection Heuristics v1

## Core Principle

Lawyers care about contradictions because contradictions attack credibility.

A contradiction can be more valuable than additional supporting authority.

## High Value Contradictions

### Position Shift

A party takes one position and later takes a different position.

Examples:

* pleading vs affidavit
* affidavit vs deposition
* motion vs testimony
* opposition vs discovery response

### Timeline Conflict

The chronology cannot be reconciled.

Examples:

* event occurs after it was allegedly reported
* document predates alleged knowledge
* testimony conflicts with objective dates

### Fact vs Evidence

The allegation is not supported by evidence.

Examples:

* allegation contradicted by video
* allegation contradicted by email
* allegation contradicted by records

### Document vs Document

Two documents cannot both be true.

Examples:

* complaint vs verified answer
* affidavit vs affidavit
* affidavit vs exhibit

### Witness Credibility Conflict

The witness changes material facts.

Examples:

* inconsistent testimony
* inconsistent statements
* selective memory
* inability to explain contradiction

## Litigation Value

Contradictions should be ranked by:

* materiality
* credibility impact
* procedural significance
* effect on claims or defenses

## Engine Goal

The engine should identify:

* contradiction
* source
* conflicting source
* significance
* litigation value
* suggested use
